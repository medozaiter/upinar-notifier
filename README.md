# 🔔 نظام متابعة وتنبيهات اليوبينار (UPINAR Notifier)
### جامعة فلسطين - University of Palestine

نظام أوتوميشن ذكي وخفيف جداً يقوم بفحص بوابة اليوبينار (Moodle) تلقائياً، وإجراء جرد دوري لجميع المساقات المسجلة، وإرسال تنبيه فوري عبر **بوت تيليجرام** على هاتفك عند نزول أي:
- 📝 واجب جديد (Assignment)
- 📄 ملف / سلايدات أو محاضرة (PDF / Resource)
- 📁 مجلد جديد (Folder)
- 📢 إعلان أو منتدى جديد (Announcement)
- ⏱️ كويز جديد (Quiz)

---

## 📁 هيكلية المشروع:
- `config.json`: ملف الإعدادات (الرقم الجامعي، كلمة المرور، توكن البوت، ومعرّف التيليجرام).
- `upinar_engine.py`: المحرك الأساسي للأوتوميشن (تسجيل دخول SSO عبر البوابة + فحص المواد وكشف الجديد).
- `telegram_notifier.py`: موديول إرسال الإشعارات المصممة بـ HTML للتيليجرام.
- `storage.py`: موديول حفظ سجل العناصر (seen_items.json) لتفادي تكرار التنبيهات.
- `start.bat`: ملف تشغيل مباشر بالنقر المزدوج على ويندوز.
- `test_telegram.bat`: فحص سريع للتأكد من وصول رسائل التيليجرام بنجاح.

---

## 🚀 طريقة الإعداد السريعة:

### 1. إعداد بوت التيليجرام (خلال دقيقة واحدة):
1. افتح تطبيق تيليجرام وابحث عن `@BotFather`
2. اضغط Start ثم أرسل: `/newbot`
3. اختر اسماً للبوت، ثم يوزراً ينتهي بـ `bot` (مثال: `MyUpinar_bot`)
4. سيعطيك الـ **API Token**، انسخه.
5. الآن ابحث في تيليجرام عن البوت `@userinfobot` وأرسل له أي كلمة، سيعطيك رقم الـ **Id** الخاص بك، انسخه.
6. افتح بوتك الجديد الذي أنشأته واضغط **Start** (ضروري لكي يسمح للبوت بمراسلتك).

### 2. تعديل ملف الإعدادات `config.json`:
ضع بياناتك:
```json
{
  "student_id": "120251381",
  "password": "كلمة_المرور_الخاصة_بك",
  "telegram_bot_token": "ضع_توكن_البوت_هنا",
  "telegram_chat_id": "ضع_رقم_الـ_id_هنا",
  "check_interval_minutes": 30
}
```

### 3. التشغيل:
- اختبر التيليجرام بالضغط مرتين على `test_telegram.bat`
- شغّل المراقب بالضغط مرتين على `start.bat`
