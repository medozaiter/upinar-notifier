# 🎓 UPINAR University Telegram Notifier Bot

بوت تيليجرام عام لطلاب جامعة فلسطين لمتابعة محتويات ومساقات اليوبينار (UPINAR Moodle) تلقائياً، مع تنبيهات فورية بكل جديد.

---

## ✨ المميزات الرئيسية
- 🔐 **تسجيل دخول آمن للطلاب:** تسجيل دخول عبر بوابة الطالب ونظام الموديل (SSO).
- 🔒 **حذف كلمة المرور وتشفيرها:** حذف فوري لرسالة الباسورد من المحادثة وتشفيرها بتقنية AES-256.
- 👥 **دعم متزامن لجميع الطلاب (Multi-tenant):** عزل تام لمساقات وسجلات كل طالب في قاعدة بيانات SQLite.
- 📊 **جرد شامل ومنسق للمواد:** فور التسجيل، يحصل الطالب على بطاقات منظمة بالواجبات، الكويزات، الشباتر، المحاضرات، والإعلانات.
- 🔔 **مراقبة دورية ومقارنة ذكية:** فحص دوري في الخلفية (24/7) وإرسال إشعار فوري فقط عند نزول أي عنصر جديد.
- ⚡ **أوامر تفاعلية للطلاب:**
  - `/check` — فحص فوري للمساقات الآن
  - `/report` — إعادة إرسال جرد كامل لجميع المواد
  - `/status` — عرض حالة المراقبة وعدد العناصر المؤرشفة
  - `/stop` — إيقاف التنبيهات مؤقتاً
  - `/help` — دليل الاستخدام

---

## 🚀 التشغيل السريع

### 1. الإعداد الأولي
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
```

### 2. التشغيل
```bash
python -m upinar_notifier run
```
